# dsh-locale-ru

Русская локализация интерфейса DeepSeek Harness (DSH).

## Цель

Сделать максимально полную русскую локализацию DSH через штатный механизм locale/i18n, без изменения core-файлов и без DOM-хаков.

## Принципы

- не изменять ядро DSH;
- не патчить `node_modules` вручную;
- не вмешиваться в модели, API, PowerShell, sessions и tool execution;
- использовать английский как fallback для отсутствующих строк;
- не переводить технические идентификаторы: Model ID, Provider ID, API Key, Base URL, package names, пути и конфигурационные ключи;
- плагин должен безопасно устанавливаться и удаляться штатными командами DSH.

## Статус

Проект находится на начальном этапе. Перед реализацией необходимо определить фактический locale/i18n API текущей версии DSH и существующие namespace/translation keys.

## План

1. Исследовать штатный locale-плагин DSH.
2. Собрать список namespace и ключей интерфейса.
3. Реализовать пакет `dsh-locale-ru`.
4. Добавить `ru-RU` с fallback на English.
5. Проверить загрузчик плагинов и отсутствие ошибок `loaded without registering`.
6. Проверить переключение English ↔ Русский.
7. Проверить установку, удаление и повторную установку.
